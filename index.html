Laporan & Report

Nama Aplikasi

Nama tampil di sidebar, login, halaman check-in QR, kartu member, dan laporan. Cetak ulang QR agar nama baru tampil di halaman check-in member.

Pengaturan Cabang

Nama cabang tampil di sidebar, login, dashboard, dan halaman check-in QR. Setelah diganti, cetak ulang QR bila ingin nama baru tampil di halaman check-in member.

Kode ID Member

Format AWALAN-NOMOR (awalan 1-8 huruf/angka). Admin menentukan ID untuk member berikutnya; begitu ada yang join, ID itu terpasang otomatis lalu naik satu (GYM-00150, GYM-00151, dst). Panjang angka mengikuti yang Anda tulis. Disimpan di server, jadi sama di semua perangkat. ID member yang sudah ada tidak berubah.

Link Halaman Check-In (tanpa banner Google)

Ini alamat web yang dibuka member saat scan QR. Boleh link pendek (bit.ly, dll). Jika link menuju Google Script, halaman check-in tampil seperti biasa tetapi ada banner Google yang tidak bisa dihapus. Jika memakai hosting file index.html (GitHub Pages, Netlify), tidak ada banner. Kosongkan bila tidak dipakai.

Username & Password

Akun disimpan di browser perangkat ini (localStorage). Ini pengaman akses tampilan dasar, bukan keamanan tingkat server.
